# Capture Inbox

作業中に見つかったidea、issue、question、change candidateを、現在のsourceや成果物へ即時反映せず記録する。

- `open/`: 未整理
- `triaged/`: 分類済み
- `promoted/`: durable source、output、taskへ昇格
- `deferred/`: 見送り・条件待ち
- `closed/`: 対応不要または解決済み

`type` は `idea / issue / question / learning`。`learning` は実装・検証・運用や作業から得た知見で、分かったこと・成立条件・根拠への参照を短く残す。既存正本の本文は複製しない。作業中に記録し、タスク・マイルストーンの区切りで関連する `open / triaged` の扱いを判断する。
