# Session Handoff

1. Read `SESSION_HANDOFF.md` and `sessions/SESSION_INDEX.md`.
2. Record the session result, decisions, changed files, unresolved items, and next starting point in a dated session record.
3. Add a concise row to `sessions/SESSION_INDEX.md`.
4. Replace `SESSION_HANDOFF.md` with the latest summary.
5. Do not copy full chats, emails, secrets, or case-specific private source content.
6. If no work remains, write `未決事項: なし` and retain useful result context.
7. Do not commit or push without the repository's approval boundary.
