# TECHNOLOGY GUIDELINE: Questetra

## 対象

Questetra アドオン、Questetra 上で動作するカスタムスクリプト。

## 実装制約

- Questetra の実行コンテキストと API 制約を前提にする
- 利用可能な API、HTTP 呼び出し、データ保持方法を先に確認する
- ワークフロー責務と外部サービス責務を分離する
- プラットフォーム上での権限境界を壊さない

## テスト観点

- 入出力データ形式の整合
- ワークフロー状態との整合
- エラー時の再試行と通知
- 外部 API 依存時の失敗挙動

## 非推奨 / 禁止事項

- Questetra 実行環境で使えない API を前提に実装しない
- ワークフロー責務を超える複雑な状態管理を無秩序に持ち込まない
- 権限境界を曖昧にしたまま外部連携を実装しない

## 実装前チェック

- Questetra 実行環境で使えない API を使っていないか
- ワークフロー状態依存の分岐が明確か
- アドオン責務を超える複雑なロジックを持ち込みすぎていないか
