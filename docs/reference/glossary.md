# Glossary

| Term | Meaning |
| --- | --- |
| Project Name | 人向けのproject / workspace名称 |
| Project Slug | lowercase kebab-caseの機械識別子 |
| Product Name | developmentで使う製品・serviceの人向け名称 |
| Common Core | Modelに依存しない正本、承認、evidence、handoff等の原則 |
| Project Model | Common Coreを用途別の文書・skill・lifecycleへ具体化する構成 |
| Technology Profile | runtime、integration等の技術固有文書・skill・metadata |
| AI surface | skillを利用するCodex、Claude Code、Rovo等の環境 |
| Adoption | kit未適用projectへ管理骨格とstateを導入すること |
| Bootstrap State | 適用済みkit、Model、path ownership、feature、historyの機械可読正本 |
| Baseline | 直前に受け入れたupstream contentのexact bytes |
| Ownership | pathをkit-managed、managed-merge、project-owned等として扱う契約 |
| U0 / U1 | accepted upstream / current upstream |
| L0 / L1 | accepted local / current local |
| EXTRA | targetに存在し、kitの生成対象ではないpath |
| Fail closed | 曖昧・不整合な状態で推測継続せず停止すること |
| Dry-run | targetを変更せず、予定結果を確認する操作 |
| External action | push、deploy、送信、共有、投稿、削除等、repository外の状態を変える操作 |
| Handoff | 次のsessionや担当が再開するための現在地と判断の記録 |
