# Support

## 公開後に受け付ける内容

- 利用方法の質問
- 再現可能なbug report
- documentation改善
- Project Model / Technology Profileの提案
- Pull Request
- security report

受付方法は[CONTRIBUTING.md](../../CONTRIBUTING.md)、security問題は[SECURITY.md](../../SECURITY.md)を参照する。

## Reportに含める情報

- kit version
- Project ModelとAI surface
- 実行したcommand（Secretを除く）
- 期待結果と実結果
- 最小の再現手順
- 関連する公開可能なlogまたはerror
- 既存fileを変更している場合は、その範囲

credential、個人情報、会社の非公開情報、private repository URL、機密logを公開Issueへ貼らない。

## Support対象外

- 利用者project固有の業務仕様の決定
- production運用の代行
- credentialやaccountの管理
- 非対応Model / profile組合せの黙示的保証
- versionや再現情報がなく、確認不能な環境固有問題の断定

## 現在の境界

Issue FormsとPR templateはlocal fileとして準備済みだが、public repositoryの受付はまだ開始していない。
