# Concepts

`project-bootstrap-kit`を使う前に知っておくとよい設計原則をまとめる。

- [Design Philosophy](./design-philosophy.md): kitが解決する問題、解決しない問題、Common Core
- [Source of Truth](./source-of-truth.md): 正本、文書の寿命、事実と判断の分離
- [Human and AI Collaboration](./human-ai-collaboration.md): 人とAIの責務、review、完了条件
- [Approval Boundaries](./approval-boundaries.md): file変更、commit、push、外部操作の境界
- [Tailoring Small Projects](./tailoring-small-projects.md): 小規模projectで省略できるものと安全境界

具体的な導入方法は[Project Models](../project-models/README.md)で用途を選んだ後、[Getting Started](../../GETTING_STARTED.md)を参照する。
