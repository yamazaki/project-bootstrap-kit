# Maintenance Work

リリース済み・運用中の既存能力に対する修正、調整、互換性を保つ小規模追加を管理する。詳細な判別と線間遷移は `../../WORK_LINE_ROUTING.md` を正本とする。

## 受付と終了

1. 索引で重複・関連案件を確認する
2. 次の `MNT-N` を採番し、受付時に索引行を追加する
3. 着手時にstatusを `🔄` へ更新する
4. 関連する `SPEC / ADR / REF / TECHNOLOGY / VERSIONING` を確認する
5. 実装、テスト、必要な受入準備を行う
6. `mnt-{N}-{slug}.md` に変更、検証、残リスク、正本更新、関連案件を記録する
7. 利用者確認が必要な場合は完了扱いにせず、確認待ちを明記する

## 索引

| ID | 受付日 | 起点 | 対象 | status | 詳細 | commits / release |
|---|---|---|---|---|---|---|

## 件別記録テンプレート

- ID / status / 受付日 / 完了日
- 起点と対象の運用中baseline
- 実施内容と変更ファイル
- 検証と結果。省略した検証、理由、残リスク
- 正本へ反映した事項
- ハマりどころと再利用可能な知見
- 関連OPS、ADV、Epic
- 中断時の次アクション
