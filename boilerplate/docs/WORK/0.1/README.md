# WORK/0.1

新規アプリケーションまたはサービスの初期構想を整理するための作業領域。

初期構想文書:
- `idea.md`
- `product_definition.md`
- `interaction_design.md`
- `phase_definition.md`
- `roadmap.md`
- `implementation_ready_checklist.md`

役割:

- `idea.md`: 発想の起点、観察した課題、期待する変化を短く記録する
- `product_definition.md`: 要求、初期提供範囲、技術構成、非機能要件を具体化する
- `interaction_design.md`: GUI / CLI / Chat / API を含む利用体験と操作境界を整理する
- `phase_definition.md`: PoC と初期実用提供をどのフェーズで検証・実現するか定義する
- `roadmap.md`: `docs/ROADMAP.md` へ反映する前の初期構想を整理する

WBS は別の下書き文書を作らず、`docs/PLAN_PHASE_CURRENT.md` を正本として直接作成・更新する。

採用技術は初期化時に未確定でもよい。技術候補が確定した時点で `docs/TECHNOLOGY/INDEX.md` と `ADOPTION.md` を確認し、必要なTechnology Profileを追加する。
