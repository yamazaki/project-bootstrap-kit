## 1. 開発成熟度の定義

- 技術実現性検証: 採用技術と構成で中核処理を実現できるか確認する
- 構想・利用体験検証: 想定利用者が意図した価値や体験を得られるか確認する
- 初期実用提供: 実際の利用者が最低限継続利用できる状態を整える
- 本格提供・拡張: 信頼性、運用性、規模、機能を拡張する
