# 見送り事項台帳

初期構想で後続フェーズや長期バックログへ送ると決めた事項を記録する。既存の台帳がある場合はその正本に追記する。見送り事項がなければ雛形の記入は不要。

現在フェーズの最終マイルストーンと完了の定義、および `docs/ROADMAP.md` の関連アウトプットから、記入した台帳を参照する。フェーズ終了時と次フェーズの WBS 作成時に全項目を確認し、確認済みの行も残す。

- 未反映／継続の場合は、現時点の送り先、再検討時期と観点を記録する。
- 反映済みの場合は WBS の番号など反映先を記録する。不要の場合は判断理由を記録する。
