# Cross-project Advisory

本プロジェクトの経験を、他プロジェクト、別の取り組み、またはプロジェクト化前の企画へ活用する相談、提案、レビュー、文書提供を管理する。詳細な判別と線間遷移は `../../WORK_LINE_ROUTING.md` を正本とする。

## 受付と終了

1. 索引で同じ相談先、主題、既存成果物を確認する
2. 次の `ADV-N` を採番し、受付時に索引行を追加する
3. 継続案件では既存の件別記録と成果物正本を読む
4. 元プロジェクト固有の事実と、一般化できる知識を分離する
5. `adv-{N}-{slug}.md` に前提、参照資産、判断、往復履歴、残フォローを追記する
6. 継続改訂する成果物は `assets/adv-{N}/` に正本を置く
7. 本プロジェクト側の変更が必要ならMNTまたはEpicを起票してリンクする

他プロジェクトへ渡す内容には、secret、credential、顧客・組織・個人情報、内部URL、元プロジェクトだけで通用する識別子を含めない。外部への送信、commit、pushは別の確定操作として扱う。

## 件別記録テンプレート

- ID / status / 受付日
- 相談内容と前提
- 参照した本プロジェクトの資産
- 提供した判断と適用条件
- 成果物正本
- 日付付きの往復履歴
- 汎用化した学び
- 関連MNT、Epic、knowledge feedback
- 残フォローアップ
